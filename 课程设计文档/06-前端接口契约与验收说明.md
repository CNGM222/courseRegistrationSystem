# 前端接口契约与验收说明

版本：V1.0，2026-09-23。前端：`frontend/`。功能基线：《02-需求分析文档》。本文件补全设计文档第 6 章的 JSON 类型，用于后端实现与联调；不是后端已实现声明。

## 1. 已确认的产品约定

1. 只对接真实 API，不提供运行时模拟模式。未登录者不能访问课程目录。
2. Vue 3 + TypeScript + Element Plus，中文浅色蓝绿色界面，桌面侧栏与移动导航。
3. 学生默认进入 `/student/registration`；教师进入 `/professor/teaching`；教务员进入 `/registrar/registration`。
4. 当前课表、选课历史和成绩单分别展示。历史页列出已结束学期，复用按学期查询本人课表接口，不新增越权的学生 ID 查询。
5. 会话失效时仅在当前标签页内存保留本人未提交选课方案。重新登录同一账号后需确认恢复；切换账号和主动退出清除；刷新标签页后不可恢复。成绩和师生个人资料不持久写入浏览器。
6. 社会安全号码允许空；非空按九位数字校验，可输入 XXX-XX-XXXX，提交时去掉连字符。列表与详情返回掩码；编辑输入留空代表不修改已存号码，不提供清除已有号码的扩展功能。
7. 新增师生只维护账号与资料，密码由后端受控初始化。前端不自行生成密码。
8. 成绩不存在时 `grade=null, version=null`；已有成绩使用实际非负版本号，包括 0。更新时 `expectedVersion` 使用相同存在性语义。

## 2. 请求与响应通则

所有接口前缀 `/api/v1`，请求与响应使用 JSON。所有实体 ID 是字符串，版本是安全范围内非负整数，金额是精确十进制字符串；如后端版本超过 JavaScript 安全整数范围，需要共同升级契约，不可隐式丢精度。

成功响应统一为：

```json
{"data": {}, "requestId": "请求关联标识"}
```

删除和退出可返回 HTTP 204 无响应体。分页数据放在 `data` 中，固定为：

```json
{"data": {"items": [], "page": 1, "pageSize": 20, "total": 0}, "requestId": "..."}
```

所有数组无结果时返回空数组，不返回 null。响应不得直接序列化 JPA 实体。详细 TypeScript 定义见 `frontend/src/types/api.ts`。

错误格式：

```json
{
  "code": "VALIDATION_ERROR",
  "message": "请修正输入内容",
  "details": [{"field": "birthDate", "message": "出生日期不能晚于今天"}],
  "requestId": "..."
}
```

HTTP 401 未登录，403 无权操作，404 指定资源不存在，409 业务竞争/关联限制，412 版本过期，422 校验失败，428 缺版本，503 依赖不可用。错误须提供可读中文原因，details 可带 field、offeringId、enrollmentId 和 message，便于定位问题，不能包含 SQL、堆栈、完整 SSN 或密码。

特殊空状态：本人课表不存在返回 `404 + SCHEDULE_NOT_FOUND`；尚未关闭的学期查询关闭结果返回 `404 + REGISTRATION_NOT_CLOSED`。普通接口不存在或后端尚未实现的 404 不能伪装为业务空状态。

写请求使用 Cookie + CSRF；对象编辑使用 `If-Match: "版本号"`。响应中的 `version` 与 ETag 表示同一数字版本，后端必须在锁定对象后核对。教师授课方案返回独立方案版本（可沿用教师档案版本）。首次创建课表不带 If-Match，其余变更带现有版本。

一般请求前端 15 秒超时，关闭注册 120 秒超时；超时不等于操作失败，界面先要求重新查询结果，不自动重放写请求。目录服务端仍必须按既定 10 秒预算处理成功或明确失败。

## 3. 认证与学期

| 路径与方法 | 契约 |
| --- | --- |
| GET /auth/csrf | `data={token, headerName}`；默认 headerName 为 X-CSRF-TOKEN，返回当前会话有效令牌 |
| POST /auth/login | 请求 `{username,password}`，同样需 CSRF；响应 CurrentUser，服务器设置 HttpOnly Session Cookie 并轮换会话 |
| GET /auth/me | 返回 CurrentUser；未登录返回 401 |
| POST /auth/logout | CSRF 校验后服务端会话失效，返回 204 |
| GET /semesters | 返回 Semester 数组；历史学期包含 CLOSED 状态，便于成绩和历史课表选择 |

CurrentUser：`{accountId, personId, role, displayName, username}`。role 为 STUDENT / PROFESSOR / REGISTRAR；师生 personId 必填，教务员可省略。后端必须校验停用和锁定状态，不能从请求体读取任意角色。

Semester：`{id,code,name,startDate,endDate,registrationStart,registrationEnd,addDropEnd,status,currency,version}`。日期 YYYY-MM-DD；业务时刻必须含 UTC 时区偏移。前端用 Asia/Shanghai 显示时间并识别已结束学期。状态 PREPARATION / OPEN / CLOSED；开放判断为 OPEN 且开始时刻不晚于当前、当前严格早于加退课截止。服务端最终再次校验时钟及状态。

## 4. 课程目录与教学班

| 方法与路径 | 参数与响应 |
| --- | --- |
| GET /semesters/{id}/offerings | query：page、pageSize、keyword、department；响应分页 Offering，另在 data 中提供 snapshotVerifiedAt 和 departments（该学期完整院系列表，不能仅取当前页） |
| GET /offerings/{id} | 返回完整 Offering；只能返回当前用户可见目录内容 |
| GET /semesters/{id}/offering-availability | query：重复参数 `ids=100&ids=101`，上限 6；返回对应 Offering 数组，确保显示信息与人数一致 |

Offering 必填结构：

```typescript
{
  id: string; semesterId: string; courseId?: string;
  courseCode: string; courseName: string; department: string; credits: number;
  sectionCode: string; professorId?: string; professorName?: string;
  prerequisites: string[]; // 可读先修课程名称/代码
  meetings: {weekNo: number; weekday: number; startPeriod: number;
             endPeriodExclusive: number; room?: string}[];
  enrolledCount: number; minStudents: 3; maxStudents: 10;
  status: 'OPEN' | 'CLOSED' | 'CANCELLED'; cancelReason?: string;
  tuition: string; currency: string; version: number;
}
```

时间记录按实际周次展开；节次是半开区间。目录同步失败或无有效快照返回 503，不能用空 items 掩盖异常。目录只读，本期没有课程 CRUD 页面。

编辑页每 5 秒查询当前至多六个选择的人数；隐藏标签页暂停，重新聚焦刷新。轮询只更新展示，不预占名额；预检与最终提交仍由后端校验。

## 5. 学生课表与成绩

Schedule 响应：

```typescript
{
  id: string; semesterId: string; status: string; version: number;
  draftRevision: number | null; submittedRevision: number | null;
  latestRevision: number; firstSubmittedAt: string | null;
  draftChoices: Choice[]; submittedChoices: Choice[];
  enrollments: Enrollment[];
}
type Choice = {offeringId: string; kind: 'PRIMARY'|'ALTERNATE'; priority: number};
type Enrollment = {
  id: string; offeringId: string; state: 'ENROLLED'|'DROPPED'|'CANCELLED';
  source: 'PRIMARY'|'ALTERNATE'; reason?: string; offering: Offering;
};
```

Enrollment.offering 必须附带可显示的冻结课程信息，以便旧目录不可用时仍能读取现有课表和历史。draftChoices 是当前草稿指针的全部明细，submittedChoices 是已提交指针的全部明细；不能把两者混为一组。未指向版本返回 []。

| 方法与路径 | 请求与行为 |
| --- | --- |
| GET /students/me/schedules/{semesterId} | 返回 Schedule 或约定的课表不存在错误；用于当前课表、历史和结果核对 |
| PUT /students/me/schedules/{semesterId}/draft | `{primaryOfferingIds: string[],alternateOfferingIds: string[]}`，备选数组顺序即优先级；返回完整 Schedule 和新 version；不更改 Enrollment |
| POST /students/me/schedules/{semesterId}/validate | `{draftRevision}`；返回 `{valid,issues,affectedOfferings}`；issues 每项含 code、message，可含 offeringId/field；不占位 |
| POST /students/me/schedules/{semesterId}/submit | `{draftRevision}` + If-Match；返回完整 Schedule；四主选同时成功或整体回滚，备选不占位 |
| DELETE /students/me/schedules/{semesterId} | If-Match；撤销有效注册及方案指针；成功 204，保留历史引用 |
| GET /students/me/report-cards/{semesterId} | 返回 `{semesterId,semesterName,items}`；只允许本人的已结束学期 |

ReportCard.items：`{enrollmentId,offeringId,courseCode,courseName,sectionCode,professorName,grade,version}`。grade 为 A/B/C/D/F/I 或 null。未录入与 I 不等价；不能映射为 0 或 F。无成绩信息时返回空列表/未录入项，供界面显示。成绩响应必须 `Cache-Control: no-store`。

初次正式提交必须 4+2；保存草稿和已有提交历史后的加退课允许 0..4 主选、0..2 备选。后端不可只依赖前端数量校验。重复课程、先修、容量与时间冲突返回带具体课程信息的错误。

版本或网络错误后，前端可“读取最新课表”更新正式结果并保留本地方案用于比较，重新保存前不自动提交。首次加载未完成时不得将空数组误认为用户主动清空方案。

## 6. 教师授课与成绩

| 方法与路径 | 响应或请求 |
| --- | --- |
| GET /professors/me/teaching/{semesterId} | `{version,eligibleOfferings,selectedOfferingIds,selectedOfferings}`；均为本人范围；已结束学期也提供 selectedOfferings，供班级名单入口使用 |
| PUT /professors/me/teaching/{semesterId} | `{offeringIds}` + If-Match，提交完整目标授课集合；返回同结构新版本 |
| GET /professors/me/offerings/{id}/roster | `{offering,canEditGrades,students}` |
| PUT /professors/me/offerings/{id}/grades | `{entries:[{enrollmentId,grade,expectedVersion}]}`；整批原子更新，返回更新后的 Roster |

Roster.students 每项：`{enrollmentId,studentId,studentName,grade,version}`。未录入 grade/version 均为 null；已有成绩 version 可以是 0。canEditGrades 由后端根据实际授课归属、学期结束且 CLOSED 计算，前端据此显示只读或可编辑名单。即使前端隐藏编辑，写接口仍必须独立校验权限与时段。

只提交实际修改且已填成绩的行；省略项不变，grade=null 不代表清空，不接受空字符串。初次录入 `expectedVersion=null` 与已有记录 `expectedVersion=0` 必须严格区分。请求预期不存在而后端发现已存在时，返回 412 并让教师重新核对。

## 7. 教务师生维护

GET /registrar/students 与 /registrar/professors 支持 page、pageSize、keyword；keyword 可匹配 ID、姓名或账号。详情 GET /{id}、新增 POST、更新 PUT、删除 DELETE 与设计文档路径一致。

PersonRecord：`{id,accountId,username,name,birthDate,status,graduationDate?,department?,ssnMasked?,version}`。即使详情也不需要返回完整社会安全号码，避免无关暴露。后端提供 ssnMasked，例如 `***-**-1234`。前端不将其作为提交值。

新增字段：username、name、birthDate、status、学生 graduationDate 或教师 department、可选 socialSecurityNumber。更新不改 username/ID/role，只提交允许字段；留空的 socialSecurityNumber 不发送，表示保持不变。毕业日期 null 表示未填写。接口校验姓名长度、日期顺序、状态枚举、账号唯一性与敏感标识唯一性。

更新和删除必须 If-Match。存在当前注册/授课关联时停用和删除返回 409 并描述原因。成功删除返回 204，不物理清除历史成绩。新增结果返回唯一 ID；密码通过受控流程提供，不出现在此处响应或日志。

## 8. 关闭注册与财务通知

POST /registrar/semesters/{id}/close 不接受前端计算的学生名单、费用或补位结果。服务端执行整个关闭事务并返回 CloseResult。GET 同学期 /close-result 返回相同结果或 `REGISTRATION_NOT_CLOSED`。

```typescript
type CloseResult = {
  runId: string; semesterId: string; closedAt: string;
  cancelledOfferings: number; leveledSchedules: number;
  billingEvents: number; pendingBillingEvents: number;
  offerings: {offeringId: string; courseName: string; sectionCode: string;
              status: 'CLOSED'|'CANCELLED'; enrolledCount: number;
              cancelReason?: 'NO_PROFESSOR'|'BELOW_MINIMUM'}[];
};
```

pendingBillingEvents 是关闭瞬间的摘要，不能用于当作当前送达状态；界面以财务事件列表为准。教务界面展示课程最终人数，不提供学生完整成绩或越权班级名单。

GET /registrar/semesters/{id}/billing-events 支持 page、pageSize、state；state 为空表示全部。分页每项为 `{eventId,studentId,studentName?,state,attempts,nextAttemptAt,lastError,deliveredAt}`，状态 PENDING / IN_FLIGHT / RETRY / DELIVERED。lastError 须脱敏。页面每 10 秒刷新可见的通知表，也可手动刷新；发送和重试仍由后端执行，关闭浏览器不能终止重试。

关闭前端按钮需到加退课截止且仍 OPEN，必须二次确认。后端有在途事务时返回 409 + REGISTRATION_BUSY，状态不变。成功但财务未送达不回滚学期。超时后查询结果再决定后续操作，不重放关闭；后端重复关闭须返回原结果。

## 9. 功能覆盖与验证边界

| 需求 | 前端实现 | 仍需后端验证 |
| --- | --- | --- |
| FR-01 | 登录、退出、会话检查、CSRF、路由保护 | BCrypt、Session 失效、锁定与对象授权 |
| FR-02 | 目录筛选、分页、详情、时效和故障提示 | 只读目录访问、有效快照、10 秒时延 |
| FR-03 | 草稿、4+2、预检、提交、删除、历史、人数提醒 | 先修、锁、事务回滚、并发容量、有效人数 |
| FR-04 | 可教班与已选班、原子目标集合请求、失败反馈 | 资格、教师占用、时间冲突和版本锁 |
| FR-05/06 | 本人班级、名单、字母成绩编辑、改动行提交 | 名单真实性、学期限制、整批原子更新 |
| FR-07 | 本人独立成绩单、未录入与 I 区分 | 响应无缓存、学生对象归属 |
| FR-08/09 | 师生查询、增改删、掩码、表单和关联错误 | 数据唯一性、逻辑删除和账号停用 |
| FR-10 | 时点限制、关闭确认、结果与取消原因 | 补位顺序、3..10 人、事务整体成功/回滚 |
| FR-11/12 | 财务状态筛选、分页、刷新、错误摘要 | Outbox 持久重试、接收端幂等、审计 |
| NFR-08 | 1366×768 与 390×844 布局、移动导航 | 结合真实数据继续验收 |

前端自动化脚本位于 `frontend/tests`，使用仅测试环境的 HTTP 响应夹具检查界面与发出的请求，应用构建不引入这些数据。真实 Spring Boot Controller/Service、财务对接、数据库并发、备份恢复和 500/2000 用户性能未在本次前端实现中完成；不能据浏览器测试宣称这些后端指标通过。
